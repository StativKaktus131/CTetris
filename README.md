# CTetris
A Tetris clone in C using SDL3 for graphics

# tetris.c / tetris.h
This is the main File where all the game logic is handled.

# tetromino.c / tetromino.h
In here all the logic for Tetrominos, their definitions and helper methods are declard / initialized.

# util.h
includes some libraries, and defines a few properties for the game. Also features the global 'board' variable.
